# 🐍 Retro Neon Snake

Un clásico juego de Snake reimaginado con estética arcade retro y efectos de neón en HTML5 Canvas y JavaScript puro.

![Captura del juego](https://img.shields.io/badge/Neon-Snake-00ff88?style=for-the-badge&logo=javascript&logoColor=black)
![Estado](https://img.shields.io/badge/Status-Completado-blue?style=for-the-badge)

---

## ✨ Características

- 🎮 **Estilo Arcade Neón**: Gráficos con efectos de brillo y partículas.
- 🔊 **Efectos de Sonido Retro**: Audio sintetizado en tiempo real con Web Audio API (sin dependencias externas).
- 🏆 **Récords Guardados**: Puntuación más alta persistente con `localStorage`.
- 🕹️ **Dificultad Variable**: Niveles Fácil, Normal y Experto.
- 📱 **Soporte Móvil / Táctil**: Controles en pantalla y compatibilidad total con teclado (Flechas o WASD).

---

## 🚀 Cómo jugar

1. Clona este repositorio:
   ```bash
   git clone https://github.com/Garatz97/retro-snake.git
   ```
2. Abre el archivo `index.html` en tu navegador favorito.
3. ¡Diviértete!

---

## ⌨️ Controles

| Acción | Teclas |
| :--- | :--- |
| **Moverse** | `Flechas` o `W`, `A`, `S`, `D` |
| **Pausar / Reanudar** | `Barra espaciadora` |
| **Pantalla táctil** | Botones de dirección en pantalla |
